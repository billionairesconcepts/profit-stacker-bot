Why Oliver Velez inspired this bot.

Some traders teach indicators. Some teach discipline. Oliver’s public price-action lessons helped connect the missing piece: the same candle setups many traders see — but framed with moving averages, structure, and context.

The shared candle language

The developer’s own trading wins were already built around engulfing candles, rejection hammers, and 60%+ candle closes into the previous candle. Oliver’s public teaching sharpened that into an 80%+ / moving-average context.

The automation mission

Human traders hesitate, over-click, exit too early, forget partials, and miss risk warnings. Profit Stacker Bot was built to reduce that inconsistency while still letting the trader stay involved.

An open invitation

If Oliver or his community finds value in this tool, the developer is open to collaboration, feedback, and sharing successful product upside with the educator whose public work helped inspire the build.

Built for traders who read price action, not indicator noise.

The bot is designed around the visual language discretionary traders already use: candles, FL levels, moving averages, pressure, partials, and protection.

FL zone awareness

Uses manual FL horizontal zones as the working map: support, resistance, bridge, reclaim, breakdown, arch, and ribbon behaviour.

Candle-pattern logic

Looks for 60%+ / 80% style price-action bars, engulfing candles, rejection bars, and high-pressure reversal behaviour near meaningful levels.

Partial harvesting

Manual partial buttons help bank profit while leaving a runner alive. The goal is simple: take money when the market gives it.

Smart exit mode

AUTO EXIT lets the bot close when risk appears. MANUAL EXIT lets the trader temporarily take control when conviction is stronger.

Pressure gauge

Newer builds include a display-only bias meter using H1/M15 roadmap context plus M5/M1 “bucket about to tip” pressure.

Gold-first observation

Recent reports show the strongest behaviour on XAUUSD/Gold. That is where the bot’s price-action style has been shining so far.
